# Smart Lighting Automation System

This project uses an Arduino UNO and a Phototransistor to automatically control an LED based on ambient light intensity.

## Components Used
- Arduino UNO
- Phototransistor
- LED
- 220Ω Resistor
- 10kΩ Resistor

## Features
- Detects ambient light intensity
- Automatically controls LED
- Displays sensor values on Serial Monitor
- Simulated using Tinkercad
